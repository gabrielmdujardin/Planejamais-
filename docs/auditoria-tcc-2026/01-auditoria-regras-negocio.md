1. **Centralização das Regras de Domínio (`lib/domain/business-rules.ts`):** Todas as 18 políticas de negócio passaram a contar com funções puras auditáveis compartilhadas entre Server Actions, API Routes, jobs agendados, componentes React e coletor de relatórios PDF, eliminando divergências matemáticas entre telas.

3. **Validação Automatizada Dedicada (`tests/regras-negocio-rn001-rn018.test.js`):** Criados **18 testes automatizados individuais** (um para cada regra de `RN-001` a `RN-018`), todos executados via `npm test` com **100% de aprovação (`0` falhas)**.
